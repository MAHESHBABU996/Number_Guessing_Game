# 🎯 Number Guessing Game

A simple Python-based number guessing game where the computer randomly selects a number, and the player tries to guess it.

## 📌 Description

The program generates a random number between 1 and 100. The player keeps guessing until they find the correct number. After each guess, the game gives hints like "Too high" or "Too low" to help the player.

## ✨ Features

* Random number generation
* User input handling
* Hint system:

  * Too high
  * Too low
* Counts the number of attempts
* Simple and beginner-friendly Python project

## 🛠️ Technologies Used

* Python 3
* Random module

## 🚀 How to Run

1. Make sure Python is installed on your computer.

2. Clone this repository:

```bash
git clone https://github.com/your-username/number-guessing-game.git
```

3. Go into the project folder:

```bash
cd number-guessing-game
```

4. Run the program:

```bash
python main.py
```

## 🎮 How to Play

1. The computer chooses a random number between 1 and 100.
2. Enter your guess.
3. Follow the hints:

   * "Too low" means guess a bigger number.
   * "Too high" means guess a smaller number.
4. Continue until you guess the correct number.
